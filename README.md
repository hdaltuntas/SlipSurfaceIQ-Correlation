# SlipSurfaceIQ Correlation

**SPT, CPT and laboratory correlations — modern desktop GUI**

Standalone application extracted from SlipSurfaceIQ-Suite with a contemporary card-based interface (soft accents, clean typography, rounded panels).

## Features

- SPT, CPT, VS and lab test correlations
- Layered soil profile
- Multiple published correlations for φ′, cu, Es, etc.
- English / Turkish
- Project save/load

## Run

```bash
python -m pip install -r requirements.txt
python main.py
```
